# 🏥 Sanjeevani — Healthcare Web Platform

Sanjeevani is a multi-page healthcare website designed to bring medical services online — making it easier for patients to access doctors, clinics, emergency help, and pharmacy information from one place.

---

## ✨ Features

- 🏠 **Home Page** — Clean landing page with navigation to all services
- 👨‍⚕️ **Doctor Pages** — Browse available doctors and specializations
- 🏥 **E-Clinic** — Online clinic booking and consultation interface
- 🚨 **Emergency Services** — Quick access to emergency contacts and info
- 💊 **Pharmacy Section** — Medicine and pharmacy information
- 🔐 **Login & Registration** — User authentication system
- 📱 **Responsive Design** — Works on both mobile and desktop

---

## 🛠️ Tech Stack

| Technology | Purpose |
|-----------|---------|
